# SMARAN · स्मरण

*Your voice remembers, even when you can't be there.*

A family health memory and reminder prototype. You say it (through **Wispr Flow**), SMARAN understands, remembers, reminds, the family confirms, and SMARAN records it.

Next.js 15 · React 19 · TypeScript · Tailwind v4 · lucide-react. No backend and no AI API: everything runs from local state (persisted in `localStorage`).

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Deploys to Vercel as-is (no env vars needed).

## 90-second demo

1. Open the app → **Skip intro** (or walk the 5 onboarding screens).
2. **Demo** menu (top right) → **Trigger reminder**: "Mummy, medicine ka time ho gaya. 💊"
3. Tap the **Wispr Flow button**: it dictates *"Haan, maine le li."* into the box and sends it. SMARAN replies and records **BP Medicine — Confirmed at 9:07 PM**.
4. Toggle **Mobile ↔ Web**: same state, dedicated desktop layout (sidebar · content · Wispr context panel).
5. **Documents** → *Blood Report* → **Ask SMARAN about this** (or Ask → *Mummy ka latest blood report kab hai?*).
6. **Family → Mummy → health card** (share/download). Toggle back to Mobile: same state.

Also try typing/dictating: `Mummy ko 9 baje medicine yaad dilana.`, `Papa ka Dr Mehta ke saath Monday ko 5 baje appointment hai.`, `Kal Papa ka BP check yaad dilana.`, `Ye Mummy ka blood report hai.` (on Add document), `Mummy ne medicine le li.`

Demo menu also has: Add document, Create appointment, Refresh memory, Preview empty states, Reset, Replay intro, and the Demo Mode switch.

## Wispr Flow: honest note

Browser JavaScript cannot drive the OS-level Wispr Flow app. The input is a normal text area, so **real Wispr Flow can dictate into it** (hold your shortcut; configurable in Settings). The Wispr Flow button in the prototype **simulates** that dictation so the demo works without setup. UI copy never claims otherwise.

## Brand assets

No logo or Wispr Flow artwork was supplied with the brief, so:

- `SmaranLogo` (`src/components/brand.tsx`) is typographic (SMARAN + स्मरण) on the supplied palette. Swap its body for your logo file.
- The Wispr Flow mark is `public/brand/wispr-flow.svg`, a **placeholder**. Drop the official asset at the same path and every button/tag updates.

## Structure

```
src/components  SmaranLogo, WisprFlowInput/Button, MobileWebToggle, BottomNavigation, WebSidebar, ContextPanel,
                DemoControls, StatusBadge, ChatBubble, ConfirmationCard, SevenDayCalendar, cards, MemoryTimeline, HealthCard
src/screens  Onboarding, Today, Create/Understand, Reminder (+conversation), Appointments, Documents, Health, Ask, Family, Memory, Settings
public/samples  5 clearly labelled SAMPLE PDFs (no medical values), generated by scripts/make-samples.py
```

The demo clock is fixed to **Friday, Oct 23, 2026, 8:40 PM** so the seeded story is always coherent.
